# Dialog

A window overlaid on the primary content. The sensory-ui Dialog plays sounds when opening and closing.

**Pattern:** Overlay

## Import

```tsx
import {
  Dialog,
  DialogClose,
  DialogContent,
  DialogDescription,
  DialogFooter,
  DialogHeader,
  DialogOverlay,
  DialogPortal,
  DialogTitle,
  DialogTrigger,
} from "@/components/ui/sensory-ui/dialog";
```

## Sound Props

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `sound` | `SoundRole \| false` | `"overlay.open"` | Sound played when the dialog opens. |
| `closeSound` | `SoundRole \| false` | `"overlay.close"` | Sound played when the dialog closes. |
| `volume` | `number` | `1` | Per-component volume multiplier (0–1). |

## Default Sound Role

`overlay.open` on open, `overlay.close` on close.

## Usage

```tsx
<Dialog>
  <DialogTrigger>Open</DialogTrigger>
  <DialogContent>
    <DialogHeader>
      <DialogTitle>Edit profile</DialogTitle>
      <DialogDescription>
        Make changes to your profile here.
      </DialogDescription>
    </DialogHeader>
  </DialogContent>
</Dialog>
```

### Custom sounds

```tsx
<Dialog sound="notification.info" closeSound="interaction.subtle">
  {/* ... */}
</Dialog>
```

## Event Triggers

| Event | Default Sound |
| --- | --- |
| Dialog opens | `overlay.open` |
| Dialog closes | `overlay.close` |
