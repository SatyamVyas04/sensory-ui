# Components

sensory-ui extends every shadcn/ui component with semantic sound props. Each component accepts sound-related props that let you customise or disable the audio feedback.

## Sound Prop Patterns

Components follow one of three prop patterns depending on their interaction model:

### Standard

For components with a single sound trigger (click, toggle, navigation).

| Prop | Type | Description |
| --- | --- | --- |
| `sound` | `SoundRole \| false` | Sound role to play on interaction. |
| `volume` | `number` | Per-component volume multiplier (0–1). |

Used by: Button, Carousel, Checkbox, Command, Pagination, Radio Group, Slider, Switch, Tabs, Toggle, Toggle Group.

### Overlay

For components that open and close (dialogs, menus, drawers).

| Prop | Type | Description |
| --- | --- | --- |
| `sound` | `SoundRole \| false` | Sound role to play when opening. |
| `closeSound` | `SoundRole \| false` | Sound role to play when closing. |
| `volume` | `number` | Per-component volume multiplier (0–1). |

Used by: Alert Dialog, Context Menu, Dialog, Drawer, Dropdown Menu, Menubar, Navigation Menu, Popover, Select, Sheet.

### Expand / Collapse

For components that expand and collapse content in place.

| Prop | Type | Description |
| --- | --- | --- |
| `expandSound` | `SoundRole \| false` | Sound role to play when expanding. |
| `collapseSound` | `SoundRole \| false` | Sound role to play when collapsing. |
| `volume` | `number` | Per-component volume multiplier (0–1). |

Used by: Accordion, Collapsible, Sidebar.
