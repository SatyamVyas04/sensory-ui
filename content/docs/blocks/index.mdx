## How Blocks Work

Each block is a self-contained MDX page with:

1. **Title and description** — What the block demonstrates
2. **Live demo** — Interactive preview with sound pack selector
3. **Installation** — Copy-paste command to install the block
4. **Code** — Full source code you can paste into your project
5. **Sound roles** — Which roles are used and why
6. **Customization** — How to swap sounds or disable them

<Callout type="tip">
  Blocks are designed to be copied directly into your project. They use the same
  sensory-ui components you already have installed.
</Callout>

---

## Using Blocks

### Copy the code

Each block provides the full source code. Paste it into your project and adjust as needed.

### Customize sounds

```tsx
// Swap sounds for a different role
<Button sound="interaction.confirm">CTA</Button>

// Disable sounds on specific elements
<Button sound={false}>Silent CTA</Button>
```
